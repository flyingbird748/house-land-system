> 本文件由 `node tools/gen-report-rules.js` 从系统实时导出，改动汇总规则后重跑即可同步。

## 一、占位符是怎么来的

1. 原始模板 `土地房屋资产统计分析报告.md` 中的填空下划线（Word 转换后形如 `\_**\_`、
   `\____`）已统一规范化为**具名占位符** `{{令牌}}`，保存在 `server/assets/report-template.md`。
2. 报告生成时（`server/lib/report.js`）按当前统计范围内的资产自动汇总，
   逐个把 `{{令牌}}` 替换为计算值；每个令牌的取值规则写在下方对照表里，
   系统首页「分析报告 → 替代规则」按钮可随时查看同一份表格。
3. 模板正文只有一个，但令牌可复用（如 `{{截止日期}}`、`{{自有房产处数}}` 在多个章节出现）。

## 二、全局口径铁律

| 项 | 规则 |
| --- | --- |
| 统计范围 | 与左侧「单位范围」一致：系统管理员可看全部，其他角色只能看本单位及下级，普通筛选条件同样生效 |
| 面积字段 | 一律取「产权面积」（建筑面积），含「人均占用办公用房」的分子；**不使用**「办公用房使用面积」——该字段在台账中大面积缺失 |
| 第一部分占比分母 | **统计范围内全部资产面积合计**（含自有、借入、租入） |
| 第二~五部分占比分母 | **自有资产面积合计**（模板注明「占比按面积统计」） |
| 自有 / 借入 / 租入 | 「是否租入借入」=借入、或「产权形式」=从政府借用 → 借入；=租入、或只填「是」且有租金 → 租入；其余 → 自有 |
| 在用 | 自用 + 借用 + 租用；出借 / 闲置 / 已拆除不计入 |
| 数值格式 | 面积保留两位小数并去尾零、带千分位；占比保留一位小数 |

## 三、需手工维护的参数（系统设置 → 报告参数）

台账里没有这些口径数据，留空时按兜底规则自动推算，也可由系统管理员在系统设置里固定下来。

| 参数 | 单位 | 用途 | 当前值 | 留空时的兜底规则 |
| --- | --- | --- | --- | --- |
| 编制干部职工人数 | 人 | 人事口径的编制数，用于「人均占用办公用房」的分母。 | （留空·自动推算） | 留空时取台账中「编制人数」的最大值；台账也没有则用「现有干部职工人数」代替。 |
| 现有干部职工人数 | 人 | 在岗实有人数。台账每条记录填的是该房产内人数，同址会重复，不能直接求和。 | （留空·自动推算） | 留空时取台账「实际人数」的**不同取值**去重后求和——同一办公区多处房产会重复填写同一个人数，直接求和会成倍虚高。 |
| 内设科室（组、中心）数 | 个 | 内设机构数量，台账无此字段，需手工维护。 | （留空·自动推算） | 留空时按标点切分资产「使用单位（使用人）」，取以「科/组/中心/办公室/部/党委/纪检组」结尾且不含「税务所」的名称去重计数。 |
| 税务所数 | 个 | 下属税务所数量，台账无此字段，需手工维护。 | （留空·自动推算） | 留空时取资产「使用单位（使用人）」中「××税务所」名称的去重数。 |
| 报告截止日期 | — | 报告口径的截止时间，会写进第二、三、四部分（「截止××××」）。 | （留空·自动推算） | 留空时取系统当天日期。 |

## 五、边界与已知约定

1. **零值措辞**：用途类占位符在该类用房为 0 处时替换为空串（模板里紧跟着句号或「，其中」），
   避免出现「主要用于无」；出租/出借为 0 处时输出「暂无出租对象 / 暂无出借对象」。
2. **人数去重**：台账每条填的是「该房产内人数」，同一办公区多处房产会重复填写，
   因此自动推算按「取值去重后求和」；若两个办公区人数恰好相同会被合并，
   精确人数请在系统设置里维护。
3. **建筑结构**：源台账无此列，已在资产表单与台账新增「建筑结构」字段；
   未填写时第五部分各项计为 0。
4. **房龄分段**：含下限不含上限（10-20 年指 ≥10 且 <20），最后一段为 50 年及以上。
5. **人均占用办公用房**的分子是**产权面积（建筑面积）**，不是「办公用房使用面积」：
   源台账的「办公用房使用面积」大面积缺失（大面积办公用房反而没填），
   且已填部分的使用率从 9% 到 28% 相差悬殊，求和会把人均算成真实值的一半左右。
   分母为「编制人数」，台账该列为空时回退到「现有干部职工人数」。
6. **历史遗留**：使用状态为「已拆除」、产权形式为「已拆除/待拆除」、
   或「无产权」且备注含「不齐全/不具备/无法办理/无审批/手续不全」的资产。
7. **数据缺口可见**：影响本次计算的缺失字段（办公使用面积、编制人数、房龄、建筑结构）
   会写入报告末尾的「附：数据完整性提示」，不会静默按 0 计入。
